CLI Commands

Three commands. Composable. Scriptable.

fetch

$ tickstore fetch SYMBOL \
    --start 2024-01-01 \
    --end 2024-12-31 \
    --provider yfinance \
    --interval 1d

Fetches OHLCV from provider, stores as candles. Idempotent.

status

$ tickstore status [SYMBOL]
$ tickstore status --all
$ tickstore status --format json

Shows stored symbols, candle counts, date ranges, last price.

indicators

$ tickstore indicators SYMBOL \
    --indicator rsi --period 14
$ tickstore indicators SYMBOL --all
$ tickstore indicators SYMBOL \
    --indicator sma --period 20,50

Computes on stored candles. Outputs table or JSON.

Technical Indicators

Pure Python implementations. No TA-Lib. No NumPy. Pure standard library math.

SMA — Simple Moving Average

sma = sum(closes[-period:]) / period

Periods: 20, 50, 200. Crossovers, trend detection.

RSI — Relative Strength Index

rs = avg_gain / avg_loss
rsi = 100 - (100 / (1 + rs))

Wilder's smoothing. Period 14 default. Overbought >70, oversold <30.

ATR — Average True Range

tr = max(high-low, |high-prev_close|, |low-prev_close|)
atr = wilders_smoothing(tr, period)

Volatility measure. Position sizing, stop-loss placement.

VWAP — Volume Weighted Average Price

vwap = sum(close * volume) / sum(volume)

Institutional benchmark. Intraday mean reversion.

Bollinger Bands

middle = sma(period)
upper = middle + 2 * std(period)
lower = middle - 2 * std(period)

Volatility bands. Squeeze = breakout signal. %B indicator.

Data Providers

Pluggable. Extensible. Each provider implements the same interface.

yfinance (default)

Yahoo Finance. Free. Daily/weekly/monthly. No API key. Rate limited.

Alpha Vantage

Free tier: 25 req/day. Intraday, fundamentals, forex, crypto. API key required.

Stooq

Free. Polish/US markets. CSV download. No API key. Limited history.

Custom Provider

Implement BaseProvider. fetch(symbol, start, end, interval) → list of candles.
